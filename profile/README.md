# PerishNet

**Making shelf-life decisions checkable, traceable and revisable when cold-chain evidence is incomplete.**

PerishNet is a knowledge-graph framework for perishable food cold chains. It connects food degradation knowledge, temperature evidence and logistics events, so that every shelf-life judgement can be checked against a model's conditions of use and traced back to the evidence behind it.

## What we work on

- **Food degradation ontology:** a structured description of perishable foods, spoilage indicators and shelf-life models.
- **Model applicability checking:** deciding whether the available evidence actually supports running a given shelf-life model.
- **Temporal assessment graphs:** linking sensor observations, temperature episodes and logistics events over time.
- **Decision support:** turning traceable shelf-life assessments into practical cold-chain decisions.
